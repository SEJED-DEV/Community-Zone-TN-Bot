# 🌐 Community Zone Bot

Professional Discord bot for temporary voice channels, advanced logging, music, and an XP-based leveling system.

## 🚀 Features

- **🔊 Temporary Voice Channels:** Automated room creation with private text chats and a powerful owner control panel.
- **⭐ Leveling System:** Reward active members with XP and milestone roles (every 5 levels).
- **🎵 Music System:** High-quality music playback from YouTube with interactive controls.
- **💰 Economy System:** Earn and spend Dinar TN (DT) in the server shop and casino.
- **🛡️ Advanced Logging:** Comprehensive audit logs for message updates, deletions, member changes, and more.
- **🎮 Social Games:** Built-in games like Mr. White and Rock-Paper-Scissors with XP betting.

## 🛠️ Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-repo/community-zone-bot.git
   cd community-zone-bot
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure environment variables:**
   Create a `.env` file in the root directory based on `.env.example`.

4. **Start the bot:**
   ```bash
   npm start
   ```

## 📁 Project Structure

- `src/` — Core bot logic and source code.
- `data/` — Persistent storage for levels, settings, and economy.
- `src/commands/` — Slash command definitions.
- `src/events/` — Discord and Lavalink event handlers.
- `src/managers/` — Business logic for voice, leveling, and music.
- `src/utils/` — Helper functions and UI generators.
